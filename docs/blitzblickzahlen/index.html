Dein Zahlenspiel für unterwegs

Auf den Startbildschirm

Öffne das Spiel in Chrome auf deinem Android-Handy.

  1. Tippe auf das Dreipunkt-Menü ⋮.
  2. Wähle „Installieren und Verknüpfung erstellen“ oder „Zum Startbildschirm hinzufügen“.
  3. Tippe auf „Installieren“.

Sobald „Offline bereit“ angezeigt wird, kannst du auch ohne Internet spielen. Starte das Spiel später über sein eigenes Symbol.
